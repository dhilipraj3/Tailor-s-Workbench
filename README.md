# Tailor's Workbench

A picture-and-voice guide that teaches you to sew a formal shirt or formal trousers from scratch.
It's designed so a child can follow it with a grown-up nearby.

- Pick a garment and a ready-made size (S–XXL shirt, waist 28–44 trousers). Every measurement can be adjusted.
- Six chapters: Tools → Machine → Measure → Draw pattern → Cut → Sew.
- Every step is an animated picture, a few words, and spoken narration (browser speech).
- The pattern drafting steps are calculated from your measurements, in inches or cm.

## Run
Open `index.html` in any modern browser. No build step or server is needed.

## Test
`node tests/smoke.js index.html` renders every scene for both garments in both units, and reports errors.
