# Image prompts for every design

One photo per design, in the app's style. Paste each prompt into your image generator (ChatGPT, Gemini, Midjourney or similar).

**How to deliver:** save each picture as `public/img/designs/<file>.jpg` with the file name shown (JPG, about 1000 × 1250 pixels). The app picks it up automatically: the design card, the customiser and the finished-garment step show the photo. The drawing is still used whenever someone changes an option, because then the photo would no longer match.

**Check before saving:** the garment must match the description (collar, sleeves, length, pockets, colour). If the generator adds a person, a hanger, text or a logo, generate it again. The background is already the app's own colour, so it needs no cutting out.
