# Sewing-step photos

56 photos: one for every distinct sewing step, shared by all designs of that garment. They use plain off-white cotton so stitches, chalk and folds show clearly; the person's own pieces, edge and seam width appear in a small inset beside each photo.

**Save as** `public/img/sew/<file>.jpg` with the file name shown (landscape, about 1600 × 1000), then run `npm run photos` or restart `npm run dev`. Check each photo shows the action described (right edge, right side of the fabric, foot on the fabric). Regenerate if it adds text, a logo or a face.
